# Задача 1: Code review

### 1. Явный импорт

В примере используется `from constellation import *`, хотя требуется только класс `Constellation`. Предлагаю заменить импорт на `from constellation import Constellation`.

### 2. Неиспользуемые объекты

В `constellation.py` объект `group = Parameters()` нигде не используется.

### 3. Название методов и описание методов

Метод `getInitialState()` заполняет `self.elements`, но ничего не возвращает. Название `initialize_elements()` точнее отражает его действие.

Для методов расчёта, полагаю, стоит описать единицы измерения аргументов (если они действительно не очевидны) и размеры получаемых массивов.

### 4. Проблема ручного управления файлами

Файл конфигурации закрывается вручную через `f.close()`. В `loadFromConfig()`, если в цикле выпадет непредвиденное исключение, ресурс останется открытым. Лучше использовать `with open(...)`, который сам закроет файл при исключении.

### 5. Повторная загрузка

В `loadFromConfig()` новые группы добавляются через `self.groups.append()`, а старые группы и счётчик спутников сохраняются. Но `groupIdx` каждый раз начинается с нуля, и из-за этого выражение `self.groups[groupIdx]` при повторной загрузке может читать старую группу, и количество спутников считается неправильно.

### 6. Индексация эпох в цикле

В `propagateJ2()` индекс для сохранения координат определяется через `epochs.index(epoch)`. Если эпохи повторяются, то метод возвращает индекс первого совпадения. То есть для `[0, 0]` координаты дважды записываются в первый срез, а второй остаётся нулевым.
