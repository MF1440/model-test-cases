# Задача 10

## Запуск

Используются библиотеки **numpy** и **scipy**. Выполнить из папки с исходниками:

```bash
python main.py
```

Результат сохраняется в `result/cells.npz` (координаты центров и литеры) и `result/report.json`.

## Решение

На единичной сфере строятся 64000 центров по алгоритму Фибоначчи. Каждому центру присваивается одна из 1008 литер. Цель — получить как можно больший минимальный угол между центрами с одинаковой литерой. Расстояния измеряются в градусах.

Для заданного порога T строится пороговый граф близких центров. Начальная раскраска выполняется методом DSATUR (Degree of Saturation — выбор вершины по насыщению), затем табу-поиск пытается устранить конфликты.

После каждой попытки проверяются все пары центров с одинаковой литерой. Сохраняется раскраска с наибольшим фактическим минимальным углом. Параметры поиска находятся в `settings.py`.

## Результат

В одном из запусков получен минимальный угол **22.13796551323874°**.

Верхняя оценка Фейеша Тота составляет примерно **27.320757°**. При распределении 64000 центров по 1008 литерам хотя бы одна литера встречается не менее 64 раз. Оценка для размещения этих 64 центров на сфере ограничивает возможный результат всей раскраски.

Самый лучший результат был получен с закомментированными входными данными в файле `settings.py`.
